# 経済指標分析ツール

## 概要

FRED APIから米国の経済指標データを取得し、Pythonを用いて経済状況を総合的かつ多角的に分析するツールです。

CPI・雇用・政策金利データを個別に分析し、分析結果をスコアリングすることで、米国経済の総合的な状況を評価します。

また、取得した経済指標のグラフ表示、前回結果との比較による経済状態の変化検出、分析レポートの生成まで実装しています。

当システムは、主に個人的な投資判断および米国経済の継続的な把握、Pythonを用いた一連の開発工程（設計から運用・保守まで）を実践することも目的としています。

---

## 主な機能

# 1. 経済指標データの取得

FRED APIを利用して、以下の経済指標を取得します。

CPI（消費者物価指数）
雇用者数
失業率
平均時給
政策金利(FF金利)

# 2. CPI分析

CPIの前年比からインフレ状況と3か月前比ベースのトレンドを分析します。

# 3. 雇用分析

雇用者数・失業率・平均時給の三つの項目を分析し、現在の雇用状況と3ヶ月前比ベースのトレンドを判定します。

各指標をスコアリングし、複数の雇用指標を総合的に分析します。

# 4. 政策金利分析

政策金利の水準および3か月前比での変化を分析し、金融政策の方向性を分析します。

# 5. 総合分析

CPI・雇用・政策金利の分析結果をスコアリングし、経済状況を総合的に分析します。

# 6. グラフ可視化

取得した経済指標を時系列グラフとして表示します。

# 7. 分析履歴の保存

分析結果をCSVファイルに保存し、過去の分析結果を蓄積します。

# 8. 前回結果との比較

現在の分析結果と前回の分析結果を比較し、各指標や総合スコアの変化を確認します。

# 9. 経済状態の変化検出

前回の分析結果と比較し、CPI・雇用・金融政策やそのスコアに変化があった場合、その変化を自動的に検出します。

# 10. 分析レポート生成

各指標の分析結果、総合判断、指標間の関係、経済状態の変化をまとめた分析レポートを生成します。

# 11. 分析条件の外部化

CPI・雇用・政策金利の分析に使用する閾値を "config.py" に分離しています。

分析ロジックと設定値を分離することで、分析条件を変更しやすい構成としています。

# 12. エラー処理

APIキーが設定されていない場合や、正常にデータを取得できない場合などを考慮し、分析不可の処理を実装しています。

# テスト

"pytest" を使用して各分析ロジックおよび履歴管理機能のテストを実施しています。

現在、以下のテストを実装しています。

* CPI分析
* 雇用分析
* 政策金利分析
* 総合分析
* 履歴保存
* 前回結果との比較
* 経済状態の変化検出
* 異常系・境界値のテスト

合計 39件のテストを実装済みです。

# 環境構築

# 1. リポジトリを取得

git clone <repository-url>
cd economic_tool

# 2. 必要なライブラリをインストール

pip install -r requirements.txt

# 3. FRED APIキーを設定

プロジェクトフォルダ内に ".env" ファイルを作成し、以下の形式でAPIキーを設定します。

FRED_API_KEY = your_api_key

APIキーはGitHub上に公開しないよう、".gitignore" で ".env" を管理対象外としています。

---

# 実行方法

以下のコマンドを実行します。

"python main.py"

実行すると、FRED APIから経済指標を取得し、各指標の分析から総合分析まで行います。
また、グラフ表示、前回結果との比較、経済状態の変化検出、分析レポートの生成も行います。

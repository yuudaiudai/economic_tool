---経済指標分析ツール---

# 概要
FRED APIから米国の経済指標データを取得し、Pythonを用いて経済状況を分析するツールです。

CPI・雇用・政策金利の各指標を分析し、スコアリングによる総合判断を行います。

また、取得した経済指標をグラフとして可視化する機能を実装しています。

# 使用ツール、ライブラリ等
・Python
・FRED API
・pandas
・matplotlib
・python-dotenv
・Git / GitHub

---主な機能---

# 1. 経済指標データの取得
FRED APIを利用して、以下の経済指標を取得します。

* CPI（消費者物価指数）
* 雇用者数
* 失業率
* 平均時給
* 政策金利

# 2. CPI分析
CPIの前年比ベースでのインフレ状況と3ヶ月前比トレンドを判定します。

# 3. 雇用分析
雇用者数・失業率・平均時給を分析し、前年比ベースで雇用状況と3ヶ月前比トレンドを判定します。

# 4. 政策金利分析
政策金利の水準と過去からの変化を分析し、金融政策の方向性を判定します。

# 5. 総合判断
CPI・雇用・政策金利の分析結果をスコアリングし、米国経済状況を総合的に判断します。

# 6. グラフ可視化
取得した経済指標を時系列グラフとして表示します。
CPIグラフ、政策金利グラフにはそれぞれ政府による誘導目標の線を設定しています。

---環境構築---
# 1. リポジトリを取得
bash
git clone <repository-url>
cd economic_tool

# 2. 必要なライブラリをインストール
bash
pip install fredapi pandas matplotlib python-dotenv

# 3. FRED APIキーを設定
プロジェクトフォルダ内に `.env` ファイルを作成し、以下の形式でAPIキーを設定します。

text
FRED_API_KEY=your_api_key

※APIキーはGitHub上に公開しないよう注意してください。

## 実行方法
以下のコマンドを実行します。

bash
python main.py

実行すると、CPI・雇用・政策金利の分析結果ならびにグラフが表示されます。
